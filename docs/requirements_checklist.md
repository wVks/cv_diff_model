# Соответствие требованиям этапа 1

Основание: PDF «РК 1. Разные методы генерации из диффузионных моделей»,
общий формат сдачи из `проект.docx`.

| Требование | Материал |
|---|---|
| Постановка задачи и ограничения | Отчёт, раздел 1 |
| Источники, объём, разбиение, лицензии, предобученная модель | Отчёт, раздел 2; README |
| DDIM, DPM-Solver++ второго порядка, Heun, параметризации и EDM | Отчёт, разделы 3–4 |
| Согласование входов и предсказаний DDPM | `stage1/model.py`; отчёт, раздел 3; тесты |
| Готовый baseline Diffusers и фиксированные шумы | `stage1/model.py`, `stage1/experiment.py`; `manifest.json` |
| Численные FID, NFE и время генерации | `artifacts/baseline/results.json`; отчёт, раздел 5 |
| Визуальная проверка baseline | `generated_grid.png`, `real_grid.png`; отчёт, раздел 5 |
| Оси сравнения, конфигурации, критерии успеха | Отчёт, раздел 7 |
| Подбор опорных уровней с сохранением порядка и MSE к длинной траектории | Отчёт, раздел 8 |
| Выборки, число прогонов и сопоставимость | Отчёт, разделы 6–8 |
| Новые начальные шумы и перенос расписания на другой сэмплер | Отчёт, раздел 8 |
| Конкретный план этапа 2 и риски | Отчёт, раздел 9 |
| Промежуточный PDF на 4–6 страниц | `report/stage1_report.pdf` |
| Код и инструкция запуска | Репозиторий и README |

Этап считается завершённым после получения `status: complete` в `results.json`,
визуальной проверки сохранённых изображений и пересборки PDF по этим результатам.
